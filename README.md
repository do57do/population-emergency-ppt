# 人口视角下的应急管理

这是一个基于 `python-pptx` 的演示文稿脚本，按照你之前整理的提纲自动生成一份 9 页的 PPT。

## 生成方法

1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

2. 生成 PPT：
   ```bash
   python generate_ppt.py
   ```

3. 输出文件：
   - `population_emergency_management.pptx`

## 主题说明

- 主题：人口要素：社会基础与应急管理的底层逻辑
- 章节：社会学概论 · 人口章节专题汇报
- 适用对象：应急管理专业学习与汇报

## 说明

该脚本会自动生成结构化的 9 页 PPT，包含：封面、目录、理论回顾、应急管理框架、核心共通点、维度对应关系、案例分析、总结和结束页。
